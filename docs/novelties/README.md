# Novelties

Ideas from this project that we haven't found anywhere else. We publish them openly, with dates, so that anyone can use them and nobody can lock them away.

Each idea has its own page with a stable ID, so it can be cited. A page says what the idea is, which public building blocks it combines, what we searched and didn't find, and how far we've got with it.

## What counts, and how one gets here

- **New, as far as we searched.** Every page says where we looked. We search public projects and documentation; we haven't searched patent databases. Many of these combine known parts, and the combination is what we didn't find.
- **From public sources and our own work.** Building blocks are cited. Nothing comes from anyone's employer or private material.
- **Proposed first, then approved.** Whoever spots a candidate, a person or an agent, opens an issue labelled `novelty` that describes it and what was searched. The maintainer decides, and an approved idea gets a page here through a pull request.
- **Kept honest.** If someone shows us the idea existed before, the page says so and links to it. The page stays, so links to it keep working.

Some of these ideas are close to established practice. They're here anyway: written down and dated, they're free for anyone to use.
